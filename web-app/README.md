# ACT — сайт записи в секции

Как открыть:

1. Распакуйте папку и откройте её в VS Code.
2. Откройте `index.html` — проще всего через расширение **Live Server** (правый клик по файлу → "Open with Live Server"), либо просто дважды кликните по файлу, чтобы открыть его в браузере.

## Структура файлов

- `index.html` — разметка всех экранов
- `styles.css` — все стили (цвета, шрифты — переменные в самом верху файла, в `:root`)
- `script.js` — вся логика: данные секций, переходы между экранами, форма записи, отправка письма
- `logo.png` — ваш логотип

## Как сайт получает рекомендацию из чат-бота

Сайт сам по себе — точка входа: отдельной "заглавной" страницы у него нет, он сразу открывается на секции, которая нужна. Бот формирует ссылку по результату теста и присылает её пользователю:

```
index.html?type=swimming&city=vladimir&age=8
```

- `type` — рекомендованный вид: `football`, `judo`, `swimming`, `art` или `theatre`
- `age` — возраст ребёнка (подставится в форму записи)
- `city` — город (сейчас не влияет на данные, они все по Владимиру — параметр оставлен на будущее, если добавите другие города)

Именно такие ссылки на разные секции вы и будете прикреплять в чат-боте под каждый результат теста. Если открыть сайт вообще без параметров, он просто покажет все секции без выделенной рекомендации — специального "демо-режима" на сайте больше нет.

## Где своя база секций

Список секций — переменная `SECTIONS` в начале `script.js`. Замените на свои данные (или позже подключите вместо неё запрос к настоящей базе/API).

## Точка интеграции с Госуслугами

В `script.js`, функция `runSteps`, отмечено комментарием `TODO(реальная интеграция)` — это то самое место, где сейчас стоит имитация записи (просто таймер), а в боевой версии должен быть настоящий вызов API Госуслуг. На экране "Оформление записи" этот шаг подписан бейджем "Демо: точка интеграции", чтобы было видно, где именно происходит переход к реальному сервису.

## Настоящие письма на почту

Форма записи по-настоящему отправляет письмо через **EmailJS** — сервис, который умеет слать почту прямо со статического сайта, без своего сервера. Библиотека уже подключена в `index.html`, осталось один раз настроить бесплатный аккаунт (5–10 минут):

1. Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com/) (есть бесплатный тариф — 200 писем в месяц).
2. **Email Services** → Add New Service → подключите свою почту (Gmail и другие поддерживаются). Скопируйте **Service ID**.
3. **Email Templates** → Create New Template. В теле письма используйте переменные, которые уже отправляет сайт — например:
   ```
   Новая заявка на запись!

   Секция: {{section_name}}
   Адрес: {{section_address}}
   Расписание: {{section_schedule}}
   Стоимость: {{section_price}}
   Статус: {{status}}

   Родитель: {{parent_name}}
   Телефон: {{parent_phone}}
   Email: {{parent_email}}
   Ребёнок: {{child_name}}, {{child_age}} лет

   Отправлено: {{submitted_at}}
   ```
   В настройках шаблона в поле **To Email** укажите `{{to_email}}` (тогда письмо пойдёт на адрес, который задан в `script.js`). Сохраните и скопируйте **Template ID**.
4. **Account** → **General** → скопируйте **Public Key**.
5. Откройте `script.js`, в самом начале файла найдите `EMAILJS_CONFIG` и впишите свои значения:
   ```js
   var EMAILJS_CONFIG = {
     serviceId: "service_xxxxxxx",
     templateId: "template_xxxxxxx",
     publicKey: "xxxxxxxxxxxxxxx",
     adminEmail: "ваша-почта@example.com"
   };
   ```
6. Сохраните файл и обновите страницу — теперь при отправке формы письмо реально придёт на указанную почту.

Пока эти три значения не заполнены (стоят `YOUR_...`), сайт работает как обычно, но на экране подтверждения честно покажет: «Письмо не отправлено: подключите EmailJS…» — так вы сразу увидите, настроено ли всё правильно.

## Фильтры

Над списком секций — одна кнопка «Фильтр» (без указания текущего выбора в самой кнопке, только точка-индикатор, если фильтр активен). Она открывает панель с чекбоксами: вид занятий и район. Пока ничего не отмечено — показаны все секции; отмечаете один или несколько вариантов — список сужается только до них. Внизу панели — кнопка «Сбросить фильтр». Разметка — в `index.html` (`.filter-bar`), логика и список районов/видов — в `script.js` (переменные `FILTER_TYPES`, `DISTRICTS` и функция `renderFilters`).

## Адаптивность

Сайт занимает весь экран на любом устройстве — без «рамки телефона» и без пустых полей по бокам. Шапка и полоса прогресса растянуты на всю ширину, а содержимое экрана центрировано на удобной для чтения ширине, кроме экрана со списком секций — там карточки сами перестраиваются в несколько колонок, если места на экране достаточно (см. класс `.stage-wide` и медиа-запрос `@media (min-width:720px)` в `styles.css`).

## Что можно поменять быстро

- Логотип и название — `index.html` (блок `.brand`) и файл `logo.png`
- Цвета — `styles.css`, блок `:root` в самом начале
- Тексты — прямо в `index.html` и в подписях внутри `script.js`
- Куда падают заявки — `adminEmail` в `EMAILJS_CONFIG` (см. выше)
